## 접근

두 대안 중 하나를 고르는 문제이므로 **쌍(pairwise) 점수 모델**로 정식화했다.
선형 점수 `s(alt) = w·f(premise, question, alt)` 를 쓰면

```
s(alt1) - s(alt2) = w · ( f(alt1) - f(alt2) )
```

이므로 **delta 특징 벡터** `f(alt1) - f(alt2)` 하나에 대해 로지스틱 회귀를 학습하면
된다 (타깃: `alternative_1`이 정답이면 1, 즉 `1 - label`).

* 대안 순서를 바꾸면 예측이 정확히 반대가 되는 **반대칭성**이 구조적으로 보장된다.
* 절편 + 질문유형 지시변수(비-delta)가 데이터셋의 위치 편향을 흡수한다
  (train label 0 비율: 전체 54.3%, 원인 57.7%, 결과 50.9%).

### 특징 (`features.py`)

| 블록 | 내용 | min_df |
|---|---|---|
| `alt_doc` | 대안 표면형: 문자 2–4gram, 어절 의사어간(앞 2음절), 어미(뒤 3음절), 어절 바이그램, **마지막 어절(서술어)** — 각 토큰의 질문유형 교차 버전 포함 | 1 |
| `cross_doc` | `전제 어간 × 대안 서술어` 상호작용 토큰 = train에서 관측된 어휘 수준 인과 연상의 sparse 메모리 | 2 |
| `NUM` | 16개 수치 특징: 길이, 전제와의 어절/어간/문자/n-gram 중복도, 부정 표현 유무 등 (표준화 후 delta) | – |
| `q` | 질문유형 지시변수 (비-delta → 유형별 위치 prior 학습) | – |

한국어 형태소 분석기가 없으므로 문자 n-gram + 어절 접두/접미 절단을 형태소 대용으로 쓴다.

최종 모델: `LogisticRegression(C=5, solver='liblinear')`, 총 168,251 차원.

## 검증 (5-fold × 5-seed, 벡터라이저·스케일러를 학습 폴드에서만 fit)

| 모델 | accuracy |
|---|---|
| 전부 0 예측 (다수 클래스) | 0.5431 |
| NUM 수치 특징만 | 0.575 |
| `alt_doc` 만 | ~0.600 |
| alt + cross + NUM (min_df=2) | 0.6120 ± 0.0060 |
| alt(min_df=1) + cross + NUM | 0.6141 ± 0.0024 |
| **+ 질문유형 지시변수 (최종)** | **0.6175 ± 0.0021** |

C는 4–9 구간에서 평평(0.6175–0.6180)하여 중앙값 C=5를 채택.
`cv_honest.py`가 위 수치를 재현한다. `cv_fast.py`는 탐색 속도를 위해 벡터라이저를
전체 데이터에 fit하는 근사 버전이며 약 +1%p 낙관적이다 — **최종 하이퍼파라미터는
모두 `cv_honest.py`(누수 없음)로 확정**했다.

## 시도했지만 채택하지 않은 것 (모두 CV 열등)

* **LSA 이중선형 상호작용** (`lsa.py`): 코퍼스 자체로 학습한 SVD 임베딩의
  `premise ⊗ alternative` 외적 → 단독 0.56, 기본 모델에 추가해도 개선 없음.
  두 대안은 보통 화제·어휘가 거의 동일해서 분포 유사도로는 구분이 안 된다.
* **역방향 데이터 증강** (`aug_exp.py`): 원인↔결과를 뒤집어 학습셋 2배 → 0.595–0.600 (하락).
* **pointwise 목적함수**(대안별 정/오 분류 후 점수 비교) → 0.600.
* **비선형 모델**: 수치 특징 HistGradientBoosting 0.559, delta의 SVD(100/250차원) +
  RBF-SVM 0.573–0.587.
* **앙상블**: LogisticRegression + LinearSVC, 4가지 특징 조합 블렌딩 → 0.610–0.622(근사 CV)로
  단일 모델과 동일. 모델 간 상관이 지나치게 높아 이득 없음.
* **추가 item-level 특징**(두 대안이 마지막 어절만 다른지, 부정 표현 불일치 등) → 개선 없음.
* **휴리스틱**: 짧은 대안 선택(0.542), 전제와 어휘 중복 큰 대안 선택(0.538) — 모두 베이스라인 이하.
* train/test 간 누수 점검: 동일 (premise, question, alt1, alt2) 조합 겹침 0건, 순서 교환 겹침 0건
  → 누수 기반 트릭 불가.

## 한계

사전학습 언어모델을 쓸 수 없어 이 과제의 본질인 세계 지식·인과 지식을 직접 활용할 수
없다. 2,460개 예시에서 얻을 수 있는 신호는 (a) 대안 표면형의 데이터셋 구성 아티팩트,
(b) train에 등장한 어휘 수준 인과 연상, (c) 질문유형별 위치 편향이며, 최종 0.6175는
대부분 (a)+(c)에서 나온다. 사전학습 한국어 LM을 쓸 수 있다면 이보다 훨씬 높은 정확도가
기대된다.
