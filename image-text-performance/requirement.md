* LLM 모델에 대해서 이미지와 텍스트에 관한 성능을 꾸준히 리포트 하는 github project를 하나 만들려고 해. 이에 대해 어떻게 하면 좋을지 플랜을 작성해줘. 일단 opus, sol, glm 세개 모델에 대해 판별할 꺼야.
일단 아래와 같은 생각을 가지고 있어.

1. 이미지와 관련해서는 (1)이미지 설명 작성, (2)이미지에 맞는 tag 추출, (3)violence 정도 판별력, (4) adult 판별력, (5) 사람 포함한 이미지 판별력 정도에 대해 각 모델별 비교를 보여주고 싶어
2. 텍스트와 관련해서는 (1)PDF 이해력, (2) 엑셀 이해력, (3) PDF extraction 능력(table 형태 포함), (4) 한글 이해력, (5) 텍스트 요약 능력, (6) 텍스트 감정 분석력, (7) Tag extraction 능력, (8) 비속어 감별 능력 정도를 모델별 비교해서 보여주고 싶어
3. 데이터브릭스에서 제공하는 모델들을 이용해서 비교해야 해(모델의 갯수와 종류는 설정으로 언제든지 추가할 수 있어야 해)
4. 위 1, 2의 판별은 수행했을 때 자동으로 뽑혀 나와야 하고 모델별로 잘 비교할 수 있게 대표적인 메트릭을 선정하고, 결과 수치와 그래프를 이용해 리포트를 자동 생성해야 해.
5. 위의 판별을 위해 필요한 데이터 셑들은 변하지 않는 표준으로 가지고 있어야 해. Kaggle과 같이 많이 사용하는 잘 알려진 곳의 데이터를 가져와서 만들면 좋겠어.

위 내 생각들을 평가해 주고, 이것을 가지고 구현이 가능할지 그리고 어떤점을 보강해야 할지를 분석해줘
