# 시나리오 2 (보험 약관 심사) 정답지

> 채점 기준의 근거. 정답은 실제 상품 「삼성 다모은 건강보험(2403)」 규칙에서 도출된다.
> 규칙 원문 발췌: `policy/samsung_damoeun_health.md`.

## 공통 판정 절차

```
1. get_contract 로 계약일·가입 특약 확인
2. get_claim 으로 진단일·진단코드·수술 확인       ← 진단일 null 이면 되묻기(B-4)
3. lookup_disease_code 로 통합암/통합소액암 분류·진단금 확인
4. get_clause 보장개시일 → 계약일+90일 전후 판정   ← 진단일 < 보장개시일이면 부지급(B-1)
5. get_clause 감액 → 진단특약(계약일 1년) 또는 다빈치(계약일 180일/1년) 감액률
6. 분류별 지급액 × 감액률 = 지급액
```

핵심: **분류가 금액을 가르고(통합암 1,000만 vs 통합소액암 200만), 감액을 곱한다.** 감액은 특약 종류마다 규칙이 다르다.

---

## B-1 — 부지급

| 사실 | 값 |
| --- | --- |
| 계약일 | 2026-01-10 |
| 보장개시일 | 2026-04-10 (계약일 + 90일) |
| 진단일 | 2026-03-20 |
| 판정 | 진단일 < 보장개시일 → 보장개시 전 |

**정답: 부지급 0원.** 근거 보장개시일 조항.

- 함정: 감액 50% 적용 500만원 / 통합암 100% 1,000만원 — 감액·지급 이전에 보장개시 전이라 지급 자체가 없다.

---

## B-2 — 지급 100만원

| 사실 | 값 |
| --- | --- |
| 계약일 | 2025-06-01 |
| 보장개시일 | 2025-08-30 (진단 후) |
| 진단일 | 2026-02-15 |
| 진단코드 | D05 = 제자리암 = **통합소액암** (진단금 200만) |
| 감액 | 계약일 1년 이내(~2026-06-01) → 진단특약 감액 50% |

**계산: 2,000,000 × 50% = 1,000,000원.** 근거 통합소액암 지급액 + 진단특약 감액.

- 함정: 감액 미적용 200만원 / 통합암 오분류 1,000만원 또는 500만원.

---

## B-3 — 지급 125만원

| 사실 | 값 |
| --- | --- |
| 계약일 | 2025-11-01 |
| 특약 | 암 다빈치·레보아이로봇수술보장특약 (가입금액 500만) |
| 암보장개시일 | 2026-01-30 (계약일 + 90일) |
| 진단·수술 | 진단 2026-02-20, 수술 2026-03-01 (보장개시 후) |
| 감액 | 계약일~수술 120일 = 180일 이내 → **25%** |

**계산: 5,000,000 × 25% = 1,250,000원.** 근거 다빈치수술특약 단계별 감액.

- 함정: 50% 적용 250만원(180일 초과로 오판) / 감액 미적용 500만원 / 통합암 진단금 1,000만 기준 계산.
- 이 케이스는 진단금(1,000만)이 아니라 **수술특약 가입금액(500만)** 기준임을 구분해야 한다.

---

## B-4 — 되묻기

진단확정일이 `null`. 보장개시일(2026-03-05) 전후 판정도, 감액 판정도 진단일 없이는 불가능하다.

**정답: 진단확정일을 되물어야 한다.** 도구 호출 없이 텍스트로 진단일을 묻는 응답이 정답.

- 함정: 계약일을 진단일로 오인해 계산 / 임의 진단일 가정.
- 채점: `ASK_PAT` 정규식 매칭. 진단확정일을 묻는 취지가 드러나야 한다.
